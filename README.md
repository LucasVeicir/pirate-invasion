# pirates invasion 

jogo para fins educacionais aplicando conceitos de motores de física, POO e uso de p5.js com a temática de invasão pirata

---
## 📚 Aprendizados
- motor de física
- sweetalert
- uso de flags
- fundamentos básicos de js

## ⚙️ Funcionalidades
- mover o canhão setas para esquerda e direita
- atirar seta para baixo
- não tem fina, acumule pontos atirando nos barcos
- a cada barco atirado ganha 5 pontos
- perde quando um barco chega a torre

## 🛠️ Stack


- JavaScript
- HTML5
- CSS3

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/LucasVeicir/pirate-invasion
```

2. Abra o arquivo `index.html` em seu navegador.
